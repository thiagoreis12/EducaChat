# Recorte confirmado do EducaChat

Atualizado em 26/08/2026, a partir das respostas do autor.

## O que o projeto é

Protótipo acadêmico de assistente virtual escolar (trabalho da disciplina de projetos / ADS). **Ainda não há escola parceira.** A vocação é uso em escolas, depois que o protótipo existir.

## Público

Estudantes **a partir do 6º ano** do Ensino Fundamental (e séries seguintes). O aluno informa a série no cadastro; o chat só usa matéria daquela etapa.

## Matérias do MVP

- Matemática
- Português
- Ciências
- Conhecimentos gerais

## Equipe

Por enquanto **só o autor**. Há colegas na sala, mas o grupo ainda não foi formado. Se entrar mais gente, atualizar o artigo (1.7 e 1.9).

## Diferencial

O sistema **não entrega resposta pronta**. Orienta pelo método socrático e restringe o conteúdo à série informada (BNCC da etapa).

## Stack combinada (ainda não implementar nesta pasta)

- Front: Vue 3
- Back: Python + FastAPI
- Usuários / série: Supabase (PostgreSQL, plano free)
- Material da série: ChromaDB local
- Quadro: Trello (Kanban)
- Código: Git
